# C2 · Exercise physiology — the maths behind every number

## Method
Read `src/lib/analysis.ts`, `data/index.ts`, `athlete.ts`, `config.ts`, `workout.ts`, `plan/generate.ts`, `plan/rules.ts`, `nutrition/targets.ts` and the Analysis/Dashboard components that render them. Bundled the library (`/home/claude/qa/work/C2/bundle.cjs`) and ran `run1.js`–`run5.js` + `run5b.js` against the seed data; outputs are saved as `run1.txt` … `run5b.txt` in the same folder. Every figure below is reproduced from those outputs or from a hand calculation shown in the row. Compared each formula with its accepted definition (Banister/Coggan PMC, Friel HR zones, Seiler intensity distribution, Riegel, ACSM/IOC/ISSN nutrition position stands, Mifflin–St Jeor, Ainsworth MET compendium, Bosquet/Wang taper meta-analyses).
Already confirmed by others and not repeated here: the 155-bpm constant for every athlete (C1-04, CODE-18, A3-22), "any activity completes the day" (C1-06, CODE-02), the Ironman legs hard-coded into Race readiness for every event (C1-02, A2-20, A3-03), wrong-sport and rest-day execution 100 % (C1-01, C1-09).
