# D1 · Layout and spacing (grid, edge alignment, spacing scale, card proportions, density, component consistency, phone layout)

## Method
Measured every page at 1440×1000 with Playwright (`work/D1/desktop.js` → `desktop.out`: bounding boxes, padding, gaps of every card, tile, control, table cell and chart label). Ran `work/D1/overflow.js`, `overflow3.js` (constrain the page to 358 px, list descendants that still overflow their parent) and `overflow4.js` (min-content width of every element) at 390×844 → `overflow.out`, `overflow3.out`, `overflow4.out`; these name the elements that push 36 of the 54 phone states past 390 px (`shots/_log.txt`). `work/D1/verify.js` → `verify.out` confirmed the builder input overlap, the stretched supplements pill, the sparkline SVG attributes and the activities grid on phone. Cited the CSS rule behind each defect from `src/app/globals.css` and `src/app/*/*.css`. Viewed `work/D1/m_*.png` phone crops and `builder2-hours.png`.
