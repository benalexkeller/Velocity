# D2 · Charts and data display

## Method
Read every chart component (`src/components/dashboard/Charts.tsx`, `analysis/Analytics.tsx`, `analysis/Panels.tsx`, `plan/RampChart.tsx`, `plan/SessionPanel.tsx` IntervalChart, `nutrition/Track.tsx`, `nutrition/WeightStages.tsx`) plus the chart CSS (`globals.css:161-193`, `analysis/analysis.css`, `activities.css`, `nutrition.css`, `plan.css`). Ran seven Playwright scripts (`work/D2/measure.js…measure7.js`) against the live app at 1440 and 390 that dumped every SVG's rendered width, viewBox, effective axis font size and tick labels, every Progress-chart axis for 4 sports × 5 metrics, tooltip text, delta arrow classes, table cell alignment, bar colours, panel overflow and the min-content width of each Analysis section (`work/D2/report.txt`, `report2.txt`, `report3.txt`, `report5.txt`). Checked 14 of my 42 screenshots plus `shots/nutrition-week-1440.png` against the code. Sports-science sanity checks limited to what a chart shows, not the maths behind it.
